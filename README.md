# Supply Chain Analytics Dashboard

A real-time Supply Chain Analytics Dashboard built using Python, SQL, Streamlit, and Tableau-ready data.

## Features
- **Inventory Tracking**: Monitor inventory levels across warehouses
- **Supplier Performance**: Analyze lead times by supplier  
- **Delivery Monitoring**: Track On-Time vs Delayed deliveries
- **Demand Forecasting**: Visualize quantity trends over time

## Tech Stack
- Python
- SQL (SQLite)
- Streamlit
- Plotly
- Pandas
- Excel

## How to Run
1. Install requirements
2. pip install -r requirements.txtjavascript2. Run the appstreamlit run app.pyjavascript
## Dataset
`SupplyChainData.xlsx` with columns: Order_ID, Product, Warehouse, Supplier, Date, Quantity, Lead_Time_Days, Inventory_Level, Delivery_Status
